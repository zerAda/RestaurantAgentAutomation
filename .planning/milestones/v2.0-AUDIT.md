## Cross-phase seams verified (8/8 connect)

1. **Canonical key** — UUID `tenants.tenant_id` is system-of-record everywhere; CI canonical `00000000-0000-0000-0000-000000000001`; no silent `'default'` on a runtime tenant path (the only annotated fallback, `useEntitlements.ts` #5, is kept-but-fail-closed-on-result).
2. **Resolution chain** — `channel_identities` (16) → W1/W2/W3 resolver + fail-closed `Apply Auth Context` (17) stamps `ci_tenant_id`; unknown identity → `UNKNOWN_CHANNEL_IDENTITY`, never `'default'`.
3. **Data-plane isolation** — order/customer writes non-defaultable (`tenant_id NOT NULL`), reads `WHERE tenant_id`; `phase-18-assertions.yml` proves A↛B both directions, keyed to the canonical UUID.
4. **Audit↔Guard cache contract (keystone)** — Redis key byte-identical on both sides: Phase-19 `audit-hook.ts` DEL == Phase-20 `W0_MODULE_GUARD` GET/SET == `entitlement-decision.mjs` `buildCacheKey` == `ralphe:entitlement:{tenant_id}:{module_key}` (ADR-0003).
5. **Fail-closed parity** — guard denies on error/missing (17/20); UI `hasModule` defaults false on loading/error with a `shared_core` no-lockout allowlist (21); internal token preflight-checked (ENT-03).
6. **Module-key alignment** — `scripts/check-module-keys.mjs`: every key in `App.tsx` + `workflows/*.json` exists in `config/product_modules.json` == seeder; zero ghosts.
7. **Two-DB coherence** — order/customer/channel_identities in the n8n DB; entitlements/audit in the strapi DB; no cross-DB write targets the wrong DB.
8. **Deferred-VPS set** — coherent, non-overlapping, ordered cutover; none blocks a CI proof.
