Produce the success-criterion-1 deliverable: a single checklist artifact
(`18-SCOPING-CHECKLIST.md`) that enumerates EVERY order/customer read and write path across the
workflows and the Strapi content types, annotates each one scoped/unscoped (with the exact current

the load-bearing artifact: it makes 18-02 a mechanical execution with zero open design choices, and it
is the auditable proof that no order/customer path was missed.

disjoint from 18-02 (which edits workflows + Strapi) and 18-03 (which edits CI/SQL files), so it runs
as an independent executor pass.
