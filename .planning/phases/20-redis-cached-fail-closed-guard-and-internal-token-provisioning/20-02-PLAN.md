<objective>
Make `STRAPI_API_TOKEN_INTERNAL` a first-class secret (ENT-03): declare it (and `STRAPI_API_URL` + the
two guard TTL envs) in both compose files' n8n services, in `config/.env.example`, annotate the secrets
inventory, and extend `scripts/preflight.sh` so a missing token fails fast with a clear message — so the
fail-closed guard (20-01) can never turn an unprovisioned secret into a silent total inbound/operator
lockout. This plan touches NO workflow files.

Purpose: ENT-03. Today the guard reads `$env.STRAPI_API_URL`/`$env.STRAPI_API_TOKEN_INTERNAL` but
NEITHER is wired into any n8n `environment:` block in either compose file, and the token is absent from
`.env.example` — so at runtime both are `undefined`, the guard's fetch 401s, and EVERY inbound message +
operator action is denied silently. The fix layers two fail-fasts: a hard `${VAR:?}` on prod compose
(can't be bypassed, fails `docker compose up` instantly) and a `preflight.sh` REQ_VARS entry (the
CI-testable, docker-free gate). To avoid breaking local/CI `compose config` while the token is
unprovisioned (Pitfall 6 / O-2), prod is hard, base/dev is soft + backed by preflight.

Output: edits to `docker-compose.hostinger.prod.yml`, `docker-compose.base.yml`, `config/.env.example`,
`docs/SECRETS_ROTATION_REQUIRED.md`, `scripts/preflight.sh`, plus an appended ENT-03 job in the
`phase-20-assertions.yml` that 20-01 creates. These files are DISJOINT from 20-01 (the guard JSON + seam)
and 20-03 (the classifier + alert wiring) — the ONLY shared file is the CI gate, which 20-01 CREATES and
this plan APPENDS a job to (20-01's jobs left intact). This plan makes NO workflow edits.

🔴 VPS DEFERRED (do NOT attempt): provisioning the REAL `STRAPI_API_TOKEN_INTERNAL` value (a
Strapi-admin-generated internal API token) into the prod env, and confirming `STRAPI_API_URL` points at
the in-network Strapi (`http://strapi:1337`). The hard `${VAR:?}` on prod is the desired guarantee that
prod n8n won't start tokenless — but the value itself is set on the VPS, not here.
</objective>
