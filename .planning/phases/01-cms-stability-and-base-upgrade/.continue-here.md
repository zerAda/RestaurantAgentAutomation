**Task 1 — VPS CMS rebuild and health verification: DONE**

- `tsconfig.json` had `"module": "ESNext"` → compiled to ESM → Strapi require() → Node 20.19+ loadESMFromCJS → named CJS imports fail one by one
- Fix: `"module": "CommonJS"` + `"moduleResolution": "Node"` in `inventory-cms/tsconfig.json`

All crash causes fixed:
1. lodash/fp ESM named imports → fix-lodash-fp.js (19 nested installs) [Strapi upstream bug]

3. system-config controller missing → created `controllers/system-config.ts`
