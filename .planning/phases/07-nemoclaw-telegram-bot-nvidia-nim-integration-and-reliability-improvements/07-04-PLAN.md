**Step 6: Write README.md:**
```bash
ssh deploy@72.60.190.192 'cat > ~/nemoclaw-repo/README.md << '"'"'EOF'"'"'
# NemoClaw Bot

A Telegram AI agent powered by [NVIDIA NIM](https://build.nvidia.com) (meta/llama-3.3-70b-instruct) and [OpenClaw](https://github.com/openclaw).

## Bot
- Telegram: @AdelClaw_Nemobot

## Setup

### Prerequisites
- Node.js 20+
- [openclaw](https://www.npmjs.com/package/openclaw) (`npm install -g openclaw@2026.3.11`)
- NVIDIA API key from [build.nvidia.com](https://build.nvidia.com/settings/api-keys)
- Telegram bot token from [@BotFather](https://t.me/BotFather)

### Install

```bash
# 1. Clone
git clone https://github.com/YOUR_USERNAME/nemoclaw-bot
cd nemoclaw-bot

# 2. Set credentials
cp .env.example ~/.nemoclaw/credentials.json
# Edit credentials.json with your NVIDIA_API_KEY and TELEGRAM_BOT_TOKEN

# 3. Copy openclaw config
cp config/openclaw.json.template ~/.openclaw/openclaw.json
# Add your NVIDIA_API_KEY to ~/.openclaw/openclaw.json

# 4. Install NemoClaw plugin
npm install -g nemoclaw  # or: openclaw plugins install ./path/to/nemoclaw

# 5. Start
bash scripts/start.sh
```

### Auto-start (systemd)
```bash
cp systemd/nemoclaw.service ~/.config/systemd/user/
loginctl enable-linger $USER
systemctl --user daemon-reload
systemctl --user enable nemoclaw
systemctl --user start nemoclaw
```

## Architecture

```
Telegram → telegram-bridge.js → openclaw agent --local → NVIDIA NIM API
                                                        ↗ meta/llama-3.3-70b-instruct
```

## License
MIT
EOF'
```
