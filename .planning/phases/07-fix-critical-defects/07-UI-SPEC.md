## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps (`gap-1`, `gap-1.5`), inline badge padding |
| sm | 8px | Compact toolbar element spacing (`gap-2`, `gap-3`) |
| md | 16px | Default element spacing (`p-4`, `gap-4`) |
| xl | 24px | Section padding (`p-6`, `py-6`) |
| 2xl | 32px | Page-level spacing (implicit via `space-y-8` = 32px Tailwind gap) |
| 3xl | 64px | Reserved for outer page-level margins |

Exceptions:
- `p-5` — 20px (non-standard, preserved from existing implementation) — card padding (`px-5 py-4` for table cells; `p-5` for stat cards). Matches existing AuditLogView card padding — do not change.
- Touch targets for pagination buttons: `p-2` (8px) wrapping a 16px icon = 32px total — below the 44px min but acceptable for desktop-only admin panel.

**Source:** Measured from `AuditLogView.tsx` existing implementation. Do not change.

## AUDIT-03 Fix Contract

The single UI change in this phase is correcting the fetch URL in `AuditLogView.tsx`.

**Current (broken):**
```ts
const url = `${apiBase}/webhook/v1/internal/audit-query?${params}`;
```

**Required (correct):** The path must match the W_AUDIT_QUERY webhook path registered in n8n. The executor must verify the exact webhook path from `workflows/W_AUDIT_QUERY.json` before writing the fix. The contract is:
- `apiBase` comes from `import.meta.env.VITE_N8N_URL` (already correct in the file)
- The path segment `/webhook/v1/internal/audit-query` must match the `path` field inside the W_AUDIT_QUERY webhook trigger node

No other lines in `AuditLogView.tsx` change. No layout, color, typography, or spacing changes.

## Interaction States — AuditLogView Reference

These states already exist in the component and must be preserved exactly as-is after the fix:

| State | Trigger | Visual |
|-------|---------|--------|
| Loading | Initial fetch | `Loader2` spin icon + "Loading audit trail…" centered in table area |
| Error | `res.ok === false` or network failure | `XCircle` icon (red/50 opacity) + error heading + raw error detail + "Retry" button |
| Empty | Fetch succeeds, `records.length === 0` | `Activity` icon (zinc-700) + empty state copy |
| Populated | Fetch succeeds, records present | Full table with stat strip, toolbar, pagination |
| Refreshing (silent) | Auto-refresh or manual refresh button | `RefreshCw` spins on refresh button; existing records remain visible |
| Auto-refresh active | `autoRefresh === true` | Live button uses `bg-brand-primary/10` tint; `Activity` icon pulses |
