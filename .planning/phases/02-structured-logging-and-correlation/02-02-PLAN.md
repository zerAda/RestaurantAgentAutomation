     N8N_LOG_FORMAT    — "text" (default) or "json" (NDJSON to stdout)

     N8N_LOG_OUTPUT    — "console"|"file"|"console,file" (default: "console")

     - workflow_id  -> workflowId (n8n native field)
     - execution_id -> executionId (n8n native field)
     - step         -> message (contains node/step name in n8n workflow execution logs)
     - timestamp    -> timestamp (n8n native field)
     - level        -> level (n8n native field)

     Note: n8n does NOT emit a separate "step" field — the step/node name appears in the
     "message" field (e.g. "Executing node 'HTTP Request'"). This satisfies OBS-01 as the
     step is present in structured form, just embedded in the message. -->
