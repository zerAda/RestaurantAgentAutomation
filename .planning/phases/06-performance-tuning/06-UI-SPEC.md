# Phase 6 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Phase Scope Note

Phase 6 is primarily a back-end and infrastructure phase (DB indexes, Redis eviction policy,
frontend bundle splitting, kiosk cache fix). The UI surface is minimal: one Suspense loading
fallback (admin dashboard) and one cache-path fix with no visual change (kiosk). No new
screens, no new navigation items, no new user flows. This contract defines the design constraints
that the two frontend-touching tasks must honor.

**Frontend-touching requirements:**

| Req | Task | Visual change? |
|-----|------|----------------|
| PERF-07 | Replace eager imports with `React.lazy()` in `admin-dashboard/src/App.tsx` | No — behavior only |
| PERF-08 | Measure + verify 30% bundle reduction | No — measurement only |
| PERF-09 | Fix `VerticalVideoFeed.tsx` to use `menuService` instead of raw `fetch()` | No — behavior only |

The only visual artifact that changes is the **Suspense fallback** rendered while a lazy chunk
loads. That fallback is already implemented in `App.tsx` (the animated skeleton with `bg-white/5`
pulse blocks). This contract locks that fallback to the existing pattern — it must not be changed.

## Spacing Scale

Standard 8-point scale. Both apps use Tailwind utility classes exclusively — no custom spacing
tokens defined in `tailwind.config.js` (both configs have empty `theme.extend`). Use Tailwind
default scale mapped to the 8-point base.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact element spacing, status dot margins |
| md | 16px | Default element spacing, nav item padding |
| lg | 24px | Section padding, sidebar header padding |
| xl | 32px | Layout gaps, header bottom margin |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level spacing |

Exceptions: Touch targets in kiosk use `px-10 py-5` (40px / 20px) on `.btn-quantum` to meet
44px minimum touch height. This is intentional and must not be reduced.

Source: `admin-dashboard/src/index.css` `.btn-quantum` (px-5 py-2.5), `kiosk-app/src/index.css` `.btn-quantum` (px-10 py-5)

## Suspense Fallback Contract

The only new visual element introduced in Phase 6 is the Suspense fallback shown while lazy
chunks load. This is already implemented in `App.tsx` lines 276-289. The contract is:

**Do not change the existing Suspense fallback.** It is already implemented correctly.

Current fallback (locked — do not modify):
```tsx
<div className="flex items-center justify-center min-h-[60vh]">
  <div className="space-y-4 w-full max-w-2xl px-8">
    <div className="h-8 bg-white/5 rounded-xl animate-pulse w-1/3" />
    <div className="h-4 bg-white/5 rounded-lg animate-pulse w-2/3" />
    <div className="grid grid-cols-3 gap-4 mt-8">
      <div className="h-32 bg-white/5 rounded-2xl animate-pulse" />
      <div className="h-32 bg-white/5 rounded-2xl animate-pulse delay-100" />
      <div className="h-32 bg-white/5 rounded-2xl animate-pulse delay-200" />
    </div>
    <div className="h-64 bg-white/5 rounded-2xl animate-pulse mt-4" />
  </div>
</div>
```

Visual specification of this fallback (for auditor verification):
- Background: transparent (inherits `bg-black` from body)
- Skeleton color: `white/5` (5% white opacity on black = approximately `#0D0D0D`)
- Animation: `animate-pulse` (Tailwind built-in — opacity oscillation at 2s)
- Corner radius: `rounded-xl` (12px) for text placeholders, `rounded-2xl` (16px) for card placeholders
- Layout: vertically centered in minimum 60vh; max-width 672px; 32px horizontal padding
- Stagger delay: 0ms / 100ms / 200ms on the three card skeleton columns

Source: `admin-dashboard/src/App.tsx` lines 276-289 (already implemented)

## Interaction States

No new interactive components are introduced. Phase 6 modifies existing code paths:

### PERF-07: React.lazy() wrapping

- All 14 view components wrapped with `React.lazy()` using `.then(m => ({ default: m.ComponentName }))` pattern
- 4 components remain eager: `LoginView`, `AppSwitcher`, `AIChatBubble`, `NotificationCenter`
- Interaction: navigation click → route change → Suspense fallback renders → chunk loads → view renders with `PageTransition` fade-in
- No new hover states, focus states, or animation additions

### PERF-09: VerticalVideoFeed cache fix

- Replace raw `fetch()` with `menuService.getProducts()` inside `fetchFeed()`
- Zero visual change — products render identically; only the data source changes
- Cache hit path: no loading state (products return synchronously from localStorage)
- Cache miss path: existing loading state in `VerticalVideoFeed.tsx` handles the async wait

## Accessibility

No new interactive elements are introduced. Existing accessibility attributes must not be
removed. Suspense fallback contains no interactive elements — no `aria-*` attributes needed on
skeleton elements. Add `aria-busy="true"` to the Suspense fallback wrapper div if not already
present (standard pattern for loading regions).

Minimum touch target: kiosk `.btn-quantum` is `px-10 py-5` = 40px / 20px padding. With text at
20px line-height, effective height is ~60px — satisfies WCAG 2.5.5 (44px minimum).
