  vendor libraries (recharts, framer-motion) into separate chunks:
  ```typescript
  // vite.config.ts

    rollupOptions: {
      output: {
        manualChunks: {
          'vendor-charts': ['recharts'],
          'vendor-motion': ['framer-motion'],
          'vendor-react': ['react', 'react-dom', 'react-router-dom'],
        }
      }
    }
  }
  ```
  Rebuild and re-run check-bundle-size.cjs after adding manualChunks.
