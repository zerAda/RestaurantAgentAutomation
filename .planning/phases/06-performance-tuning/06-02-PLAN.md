To establish the PERF-08 30% claim, we need a monolithic baseline. Since lazy() is already
implemented, we cannot build a monolithic version without reverting. Instead, use this approach:

1. Count the number of separate chunk files in `dist/assets/*.js` — if there are 10+ chunks
   (one per lazy route), code splitting is confirmed as active.
2. The initial bundle (the entry chunk, typically `index-*.js`) should be significantly smaller
   than the total of all chunks combined. If `index-*.js` is less than 70% of total JS, the
   30% initial bundle reduction requirement is met.
3. Report: list all JS chunks with sizes, highlight the entry chunk, calculate the ratio.

Print a summary table:
- Entry chunk: {name} — {size}KB
- Total all chunks: {total}KB
- Entry/Total ratio: {percent}%
- PERF-08 status: PASS if entry < 70% of total, otherwise needs investigation
