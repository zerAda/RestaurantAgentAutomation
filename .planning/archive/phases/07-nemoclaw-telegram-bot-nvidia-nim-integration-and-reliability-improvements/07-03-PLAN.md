Write via SSH heredoc:
```bash
ssh deploy@72.60.190.192 'mkdir -p ~/.config/systemd/user && cat > ~/.config/systemd/user/nemoclaw.service << '\''EOF'\''
[Unit]
Description=NemoClaw Telegram Bot
After=network-online.target
Wants=network-online.target

[Service]
Type=simple
ExecStart=/bin/bash /home/deploy/.nemoclaw/start.sh
Restart=always
RestartSec=10
Environment=HOME=/home/deploy
Environment=PATH=/usr/local/bin:/usr/bin:/bin:/home/deploy/.npm-global/bin
WorkingDirectory=/home/deploy/.nemoclaw

[Install]

EOF'
```

**CRITICAL fields:**
- `Type=simple` (NOT `Type=forking` — start.sh runs in foreground)
- `Restart=always` (auto-restart on crash)
- `RestartSec=10` (10-second delay before restart to avoid crash loops)
- `WantedBy=default.target` (user service target)
