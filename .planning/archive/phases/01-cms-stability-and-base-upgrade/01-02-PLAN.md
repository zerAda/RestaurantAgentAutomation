On the VPS at /opt/resto/current/, run the clean rebuild sequence. This takes 15-30 minutes — do not interrupt it.

```bash
ssh deploy@72.60.190.192
cd /opt/resto/current/

# Clean rebuild (--no-cache forces npm ci to run fresh)
docker compose -f docker-compose.hostinger.prod.yml build cms --no-cache 2>&1 | tee /tmp/cms-build.log
# Watch for: "Successfully built" or any ERROR lines

# Start new container from rebuilt image
docker compose -f docker-compose.hostinger.prod.yml up -d cms

# Flush nginx DNS cache (REQUIRED — nginx caches old CMS IP after restart)
docker exec current-gateway-1 nginx -s reload

# Wait for CMS health (cold start: 5-8 min for DB migrations)

done
echo "CMS is healthy at $(date)"
```

If the build FAILS: check /tmp/cms-build.log for errors. Common causes:
- npm ci network timeout (retry build)
- ENOSPC during build (abort, free more disk, retry)
- TypeScript compilation error (report the TS error so source can be fixed)

Do NOT restart n8n, postgres, or any other container. Only the `cms` container should be touched.
